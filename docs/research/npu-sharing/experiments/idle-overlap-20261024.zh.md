## 改动与正确性

- 导出完成后异步更新停用 DP2 的 CPU 备份；覆盖快照、恢复目标和销毁前等待，核对优化器／调度器代际与发布版本。
- CPU 备份更新与源引擎缓存停放／卸载并行，两者完成后才恢复目标 HBM。
- 保留源映射；关闭全量校验时不再重建无用 inventory，仍保留元数据和抽样检查。
- 直接复制到映射快照，使用独立 NPU 复制流，复制流完成后才发布就绪状态。
- 非阻塞轮询导出状态，避免阻塞 worker RPC；只有驻留 DP1 全模型、固定接收方 XCCL 发布可与导出并行。修改训练状态、保存／加载、显存切换和销毁仍有硬同步。
- 初始化时预热 DP2 导出；真实训练代际覆盖初始快照，预热不执行优化器更新。

18 项 CPU 测试通过，覆盖代际不匹配、错误传播和重叠契约。每个涉及训练状态的候选均先通过 NPU
完整逐字节导入校验，再关闭全量校验计时；发布重叠的正确性验证确实观测到复制未结束时发布。性能轮保留元数据／抽样检查。全部完成的比较未见沙箱上传重试。
