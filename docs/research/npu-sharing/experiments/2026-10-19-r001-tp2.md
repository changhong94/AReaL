# R001 equal-TP handoff validation — 2026-10-19

## Scope

Two equal-width tensor-parallel inference replicas, PP=1, the existing dynamic-KV Ascend
backend. This is a correctness experiment, not a fixed/shared performance comparison. It
does not establish the marginal speedup of R001.

## Implementation

- One corresponding-rank HCCL channel per TP shard.
- Validate all worker acknowledgements and model/cache geometry.
- Allocate every target shard before either replica enters HCCL transfer.
- Import every shard before resuming the request; preserve the existing one-owner
  ticket/lease protocol and same-version checks.
- Charge aggregate bytes and maximum per-rank blocking time, including preparation.
- Require exactly two inference replicas. Unequal TP widths, PP>1, resharding, and
  arbitrary multi-replica pairing are unsupported.
