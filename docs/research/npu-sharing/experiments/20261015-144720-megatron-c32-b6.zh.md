## 解释与局限

当前规划器只选择原生队列里尚未执行的请求。这些事件表示当时没有排队候选，不表示专用引擎没有运行中的工作。 这构成 R001
的动机，但不证明运行中迁移一定有收益；重放、传输和训练竞争可能抵消收益。 90.300 秒后两卡已完成推理，剩余时间不属于此次有限工作量中可利用的推理机会。

token 数按单 token 解码窗口结束事件重建；摘要审计没有分段数量差异。 这些时间不是精确的 token 发出时刻，设备执行窗口跨度也不代表独占硬件的忙碌时间。
