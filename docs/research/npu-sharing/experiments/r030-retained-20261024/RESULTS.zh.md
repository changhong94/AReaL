# 保留 DRAM 副本：六批对照结果

固定组 456.48 秒，共享组 484.17 秒，共享慢 27.69 秒（6.07%）。切入／返回累计 62.52 秒，相比上轮 68.21
秒有所降低，但没有抵消全部切换成本。共享 PPO 扣除其内部嵌套切换后为 238.26 秒，固定为 290.09 秒；不能把嵌套计时重复相加。

生成 token 数为固定 361000、共享 364037（共享多约 0.84%）。这是复用 vLLM
的开发对照，只有一轮，生成内容也并不完全相同，不能当作严格因果结论。两组没有沙箱上传重试。性能运行关闭全量校验；18 次导入只执行正常元数据检查，没有梯度诊断回放。

此前完整三批验证通过：9 次全量状态导入，第二批完整梯度误差 1.15893%，原始备份内容一致。保留副本与状态相关 41 项测试、预取与压力预算相关 36 项测试通过。

结论：机制有效减少回拷，但本样本总耗时仍差于固定组，保留为实验性可选功能。下一候选只合并切换为双卡后的剩余执行段，保留原微批次及一次参数更新，结果独立记录。
