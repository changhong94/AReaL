# 演进路线与论文候选贡献

## 恢复出的演进路线

| 阶段               | 条目                         | 决策或经验                                                                   |
| ------------------ | ---------------------------- | ---------------------------------------------------------------------------- |
| 异步与多版本可行性 | R024                         | 上游异步是基线，短暂共存不足以证明多占一张卡值得。                           |
| 单卡到借用训练卡   | R007、R012                   | 安全切换和请求所有权是前提，早期共享曾更慢。                                 |
| 权重发布关键路径   | R008、R003、R009、R010、R011 | 扁平快照、逐副本就绪、独立读取、后台收尾、末尾消除解决不同依赖。             |
| 分配与预热         | R014、R015、R016             | 同输入回放定位首次优化器和 backward 分配；JIT 解释了表面上的低请求并发。     |
| 驻留与同卡并发     | R006、R017、R018、R002       | 动态 KV 降低物理占用，部分卸载与并发准入交换显存与时间。                     |
| 批次关键路径调度   | R013、R004、R019             | 完整题目收齐重要，必须同时估计数据和训练卡就绪；更多历史和同题信息也会退化。 |
| 恢复共享卡推理能力 | R005、R020、R001             | 排队搬移找不到候选，TP2 长尾更慢，运行中再均衡仍是待验证假设。               |
| 泛化与证据         | R021、R022、R023             | Megatron、多卡、逐 rank 预算和可复现观测拓展适用范围，不自动代表加速。       |

## 可以组织的论文候选贡献（新颖性待核实）

1. **训练优先 NPU 共享的状态与版本协议。** 联合条件驻留、逐卡预算和请求/权重边界。
1. **独立发布的推理池。** 专用推理先恢复，共享快照和内存恢复在后台，量化剩余关键路径。
1. **批次关键路径的在线成本调度。** 用因果冻结统计优化 `max(数据就绪, 卡就绪)`，再研究运行中请求再均衡。
1. **诊断证据和反例。** 受控分配诊断、TP2 和同题负面实验、公开观测及工作量差异，提高结论可信度。

这是候选组织方式，不是四项已证明新颖的贡献。slab、虚拟内存、异步 RL、预取、生存估计和预热都有既有研究；撰写创新性前须明确
FineServe、CaMem/昇腾运行时的来源。

## 强结论前仍缺的工作

- 系统相关工作矩阵和真实文献来源。
- 重复完整循环、等输出回放、更广模型/长度/硬件压力；分开显存容量收益和延迟收益。
- R001 的同版本交接设计和故障测试，再做实时迁移。
- 质量与 off-policy 评估、恢复语义和长期稳定性。
- 多卡严格配对扩展实验、TP4 验证、真实 RL 中的单 rank 压力（不能只靠原生小测试）。
- 历史源码/镜像来源不完整实验的精确归因。

本轮没有新跑 NPU 实验，也没有修改生产调度逻辑。
